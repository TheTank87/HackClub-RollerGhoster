# HackClub Project-RollerGhoster

This is week 2 of my mechanical design for Hackclub Halflife. This week I will be building a Merble Marble slide thingy.

# What is it

Merbl or ROller Ghoster 2000 is my custom marble race made on Onshape. This is my first time dealing with more complex shapes on Onshape so don't expect something from another dimension, but do expect something that works. I made this project for the week2 of the half life event.

# Features

* Support beams
* Tracks
* A finishing marble catcher

# The model
This is the finished product that I have created, as you can see it doesn't look very complicated, but the steps needed here were crucial. The guide never said anythign about tracks suddenly rotating upside down when sweeping a composite curve, so I devised a method that required multiple track sketches at correct angles and different composite curves so that tracks stay upright.
